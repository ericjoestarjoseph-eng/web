# Vehicle Service Management System

React + Vite + Supabase app for an automobile service center: browse services, book appointments for customer vehicles, and view service history with billing.

## Setup
1. `npm install`
2. Create a Supabase project, then run `supabase.sql` in the SQL Editor.
3. Copy `.env.example` to `.env` and fill in your project URL and publishable key.
4. `npm run dev`
